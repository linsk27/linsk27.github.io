skills-manage AI Skills 管理器

skills-manage 是 linsk27 的 Tauri、React 和 TypeScript 桌面应用，用来集中管理本地 skills，支持 Claude Code、Codex CLI、Cursor、Gemini CLI 和 20 多个平台。

skills-manage 是一个 Tauri、React 和 TypeScript 桌面应用，用来把多个 AI coding agent 的 skills 管理集中到一个地方。它把 ~/.agents/skills/ 作为中心技能库，再通过平台安装、卸载和符号链接，把同一套技能同步到 Claude Code、Codex CLI、Cursor、Gemini CLI、Trae、Windsurf、Aider 等工具。

适合谁

  • 同时使用 Claude Code、Codex CLI、Cursor、Gemini CLI 或多个 AI coding agent 的开发者。
  • 想把本地 skills、项目 skills、市场 skills 和 GitHub 导入技能统一管理的人。
  • 需要批量安装、卸载、搜索、预览和组织 Agent Skills 的人。
  • 想参考 Tauri、React、TypeScript 桌面应用结构的人。

项目价值

skills-manage 的价值在于它解决了本地 skills 分散在不同目录、不同工具、不同市场里的管理问题。它提供中央技能库、平台视图、项目扫描、市场浏览、GitHub 仓库导入、Markdown 预览、原始源码查看、解释生成和技能集合等能力，让技能资产更容易沉淀、迁移和复用。

这个项目适合作为 Claude Code skills、Codex CLI skills、Cursor skills、Agent Skills desktop app 或 Tauri React desktop app 的本地优先应用参考。
