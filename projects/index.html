正在维护

Dev Cockpit

Dev Cockpit 解决的是“隔几天回来就忘了项目怎么跑”。它会扫描技术栈、启动命令、端口、Python 环境和 Git 状态，再把 CLI、Web 与 Electron 桌面端接到同一套判断逻辑上。资源雷达只是后来增加的一个模块，不是整个项目的全部。

技术上，它把纯 TypeScript 扫描逻辑放在 core，本地进程与端口放在 server，Vue 3 负责 Web 界面，Electron 只做桌面外壳。项目状态依赖本地可验证信号，不让 AI 猜“它是不是已经启动”。

  • 阅读开发复盘
  • GitHub：linsk-labs/local-dev-cockpit

Local AI Ops

Local AI Ops 是一个本地优先的阿里云运维工作台。React 与 ECharts 展示资产和告警，FastAPI 提供接口，PostgreSQL 保存运维资料，Redis/Celery 执行同步与健康检查，阿里云官方 SDK 负责读取 ECS、轻量服务器、OSS、域名和 DNS。

AI 只处理脱敏后的告警上下文，输出摘要和排查建议，不自动执行修复。它更像一个可信局域网里的运维索引，而不是要暴露到公网的多租户控制台。

  • 阅读架构与安全边界
  • GitHub：linsk-labs/local-ai-ops

ProofPR

ProofPR 是 GitHub Action 与 CLI 形式的 PR 证据检查器。它解析 diff 和 .proofpr.yml，用确定性规则检查测试、截图、复现步骤、依赖、workflow 权限、secret 与 MCP 配置，再输出风险等级、证据分和 review gate。

这个工具运行时不调用大模型，也不判断业务代码是否正确。设计重点是相同输入得到相同结果，让维护者能看到每条命中来自哪条规则。

  • 阅读规则引擎设计
  • GitHub：linsk-labs/proof-pr

Signal Atlas

Signal Atlas 是当前运行在 linsk27.dpdns.org 的 Three.js 工作站。生产外层基于 Henry Heffernan 的 MIT 开源作品集，并保留完整许可归因；显示器里的 linsk27 复古桌面、窗口系统、真实应用入口和内嵌适配由我重新实现。

WebGL 负责 3D 场景，CSS3DRenderer 把真实 HTML 与 iframe 对齐到显示器。这个方案比放一张屏幕贴图难得多，却可以真的打开博客、八股文和 GitHub。

  • 阅读 v0.25.7 开发复盘
  • 在线进入 Signal Atlas
  • GitHub：linsk-labs/signal-atlas

第三方开源工具：Archify

Archify 不是我的项目，而是 tt-a1i 维护的 MIT 开源工具。我把它放在这里，是因为它和这些工程项目的文档方式很契合。

它更准确的定位是“给 AI Agent 使用的技术制图 Skill”，而不是传统的在线画板：Agent 把自然语言或仓库证据整理成 typed JSON IR，Node.js CLI 先校验结构，再由 HTML/SVG renderer 生成架构图、工作流图、时序图、数据流图或生命周期图。结果可以是自包含 HTML，也能导出 PNG、SVG 等格式。
